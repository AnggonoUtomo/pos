# Rencana

1. Petakan page Inertia, baca panduan aktif dan periksa Sheet/layout existing.
2. Tulis pemeriksaan coverage guide/loader sebelum implementasi; susun konten
   dekat page dan resolver lazy tanpa dependency/backend baru.
3. Sheet shared, tombol admin/toolbar POS dan shortcut F1; jaga fokus, form,
   keranjang, viewport/scroll dan perubahan konteks saat navigasi.
4. Lint/type/build serta QA Chrome terfokus: desktop/tablet, light/dark, guide
   berbeda, keyboard, scroll, tanpa reload/mutasi. Commit tiap increment yang
   lulus, dokumentasikan hasil dan push/verifikasi setelah work item selesai.
