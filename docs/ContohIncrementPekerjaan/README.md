# Contoh Increment Pekerjaan

Folder ini berisi contoh pola dokumentasi increment dari pekerjaan sebelumnya.
Gunakan sebagai referensi bentuk `README.md`, `specification.md`, `plan.md`,
dan `tasks.md`, bukan sebagai source of truth command, opsi generator, nama
module, permission, route, atau struktur final project POS ini.

Jika ada perbedaan antara contoh ini dan dokumen utama project POS, ikuti
`AGENTS.md`, `docs/SPEC.md`, `docs/ARCHITECTURE.md`,
`docs/MODULE-COMMUNICATION.md`, `docs/QA-AUTOMATION.md`, serta work-item aktif.
