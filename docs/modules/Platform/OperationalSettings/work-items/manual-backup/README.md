# Backup Manual Dan Folder Lokal

User menyetujui tombol Backup sekarang di Operasional dan hasil dump pada
root project `backups/`, diakses File Explorer, bukan URL/unduhan publik.
Folder ini masih satu PC: bukan bukti salinan off-device. Jadwal lokal yang
disetujui22:00WIB; cron/pemicu OS tetap tugas admin, tanpa installer otomatis.

Gunakan command pos:backup existing; manual tidak mengubah status harian
backup terjadwal. Permission manage existing, audit wajib, tanpa secret/path
arbitrary atau restore database bisnis dari UI. Printer fisik belum tersedia.
